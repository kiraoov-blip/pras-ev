# 제주 전기차 시간대 지정 할인요금 매출영향 시뮬레이터

## 1. 목적

2025년 제주 전기차 완속·급속 충전 사용량을 2026년 전기자동차 충전전력요금에 적용하여, 옥토퍼스형 시간대 지정 할인요금 도입 시 전력량요금 매출 영향을 검토하는 정적 웹 시뮬레이터입니다.

## 2. 현재 반영 기준

- 분석대상: 2025년 제주 전기차 완속 50kW 미만, 급속 50kW 이상 시간대별 사용량
- 산정범위: 기본요금 제외, 전력량요금만 산정
- 시간정의: H01 = 00:00~01:00, H24 = 23:00~24:00
- 단위: kWh
- 신규 기본 할인시간: 10:00~16:00
- 기준요금: 2026년 전기자동차 충전전력요금
- 2025년 1월 27일: 평일로 보정
- 기존 봄·가을철 주말 11:00~14:00 전력량요금 50% 할인: 체크박스로 반영 여부 선택
- 기존 주말할인과 신규 할인 중복: 체크박스로 중복 허용 여부 선택

## 3. 주요 기능

1. 현행 매출과 신규요금 적용 후 매출 즉시 비교
2. 완속·급속별 현행 요금유형 선택
3. 신규 할인시간, 할인율, 고정단가, 비할인시간 단가조정률 변경
4. 요금제 참여율 조정
5. 완속·급속별 부하이전율 조정
6. 중간부하·최대부하 등 이전 원천 시간대 선택
7. 매출중립을 위한 할인시간 고정단가 자동 계산 및 적용
8. 1원/kWh 단가 조정에 따른 매출 영향 즉시 확인
9. 매출중립을 위한 비할인시간 정확 조정률 자동 계산 및 적용
10. 24시간 평균 충전부하 및 월별 매출 차트 제공
11. 매출변동 요인분해 및 시간대별 결과 CSV 다운로드

## 3-1. 매출중립 기능의 해석

- `매출중립 근사 조정률 적용`: 정확한 비할인시간 조정률을 계산한 뒤 가장 가까운 0.1%p 값을 적용합니다. 따라서 소액의 잔여 매출차이가 발생할 수 있습니다.
- `매출중립 할인시간 단가`: 이론상 매출증감이 0원이 되는 할인시간 고정단가를 계산하고, 입력에는 가장 가까운 0.1원/kWh 값을 적용합니다.
- `매출중립 근사단가 적용`: 정확값에 가장 가까운 0.1원/kWh 단가를 적용하며 소액의 잔여 매출증감이 발생할 수 있습니다.

## 5. GitHub Pages 배포 절차

### 1단계: 저장소 생성

GitHub에서 신규 저장소를 생성합니다.

예시 저장소명:

```text
jeju-ev-tariff-simulator
```

Public 저장소로 만들면 GitHub Pages 설정이 가장 단순합니다.

### 2단계: 파일 업로드

이 폴더 안의 파일과 `data` 폴더를 저장소 최상위 경로에 그대로 업로드합니다.

GitHub 웹 화면 기준:

1. `Add file` 클릭
2. `Upload files` 선택
3. `index.html`, `styles.css`, `app.js`, `README.md`, `data` 폴더 업로드
4. Commit message 입력
5. `Commit changes` 클릭

### 3단계: GitHub Pages 활성화

저장소에서 다음 경로로 이동합니다.

```text
Settings → Pages → Build and deployment
```

아래와 같이 설정합니다.

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

저장 후 1~3분 뒤 접속주소가 표시됩니다.

### 4단계: 초기 검증

웹페이지가 열리면 다음을 확인합니다.

- 상단 제목이 정상 표시되는지
- 기본 할인시간이 10:00~16:00으로 설정되어 있는지
- 핵심 결과 카드와 매출중립 할인시간 단가 분석 카드가 표시되는지
- 24시간 평균 충전부하 차트가 표시되는지
- 할인율, 참여율, 이전율 변경 시 결과가 즉시 바뀌는지

### 5단계: 데이터 교체 방식

향후 사용량 데이터를 업데이트할 경우 `data/ev_usage_2025.js`와 `data/ev_usage_2025.json`만 교체하면 됩니다.

브라우저는 `ev_usage_2025.js`를 우선 사용하므로, 데이터 업데이트 시 JS 파일의 형태는 다음 구조를 유지해야 합니다.

```javascript
window.EV_USAGE_DATA = { ... };
```

## 6. 단계별 고도화 계획

### MVP 1단계: 현재 버전

- 제주 전체 완속·급속 집계 사용량 기반 매출 영향 산정
- 전력량요금만 분석
- 할인시간, 할인율, 고정단가, 참여율, 부하이전율 사용자 조정
- 매출중립 할인시간 단가와 1원/kWh 민감도 제시
- GitHub Pages 배포

### 2단계: 요금유형 구성비 반영

현재는 완속·급속별로 하나의 요금유형을 선택하는 구조입니다. 실제 매출과 맞추려면 완속·급속별로 다음 구성비를 추가하는 것이 좋습니다.

- 자가소비용 저압·고압 비중
- 충전서비스 제공사업자용 저압·고압 비중
- 선택Ⅰ~Ⅳ 비중

### 3단계: 고객군별 분석

고객 또는 충전사업자 단위 자료가 있으면 다음 기능을 추가할 수 있습니다.

- 고객군별 참여율
- 고객군별 부하이전율
- 고객군별 매출 증가·감소 분포
- 완속·급속 외 충전소 유형별 분석

### 4단계: 기본요금 및 계약전력 반영

계약전력 또는 충전소별 최대수요전력 자료가 확보되면 기본요금을 포함할 수 있습니다.

- 현행 기본요금 매출
- 할인시간 집중에 따른 계약전력 증가 가능성
- 기본요금 포함 총매출 영향

### 5단계: 배전망 영향 검토

지역·충전소·변압기 단위 사용량이 확보되면 요금제 도입에 따른 부하집중 리스크를 분석할 수 있습니다.

- 할인시간대 신규 피크 발생 여부
- 특정 지역 충전부하 집중도
- 변압기·피더 단위 수용여력 영향

## 7. 로컬 실행

GitHub 업로드 전 PC에서 확인하려면 폴더에서 아래 명령어를 실행합니다.

## v2.3 변경사항

- 화면 예시 기준 기본값 적용: 전체, 완속 자가소비용·저압, 급속 자가소비용·고압, 기존 주말할인 반영 및 중복 허용, 10~16시, 정률 할인 70%, 비할인시간 조정률 0%, 참여율 80%, 경·중간·최대부하 이전, 완속 50%, 급속 30%, 균등배분
- 할인율, 비할인시간 조정률, 참여율, 완속 이전율, 급속 이전율에 슬라이드와 숫자 직접입력 기능을 동시에 제공
- 슬라이드와 숫자 입력값은 양방향으로 즉시 동기화
- 고정단가와 비할인시간 조정률을 각각 0.1원/kWh 및 0.1%p 단위로 입력·표시
- 매출중립 근사단가·근사 조정률은 해당 단위에서 매출차이가 가장 작은 값을 적용
- 화면 최상단은 시뮬레이터 제목만 표시


## v2.4 변경사항

- 신규 할인요금 설정 영역에 현재 할인안과 동일 할인조건의 매출중립안을 비교하는 단가표 추가
- 할인시간대와 할인시간 외 단가는 참여고객의 변경 후 사용량을 기준으로 한 가중평균 적용단가로 표시
- 매출중립안은 현재 할인율 또는 고정단가를 유지하고 비할인시간 단가 조정률만 0.1%p 단위로 계산
- 매출중립 근사 조정률 적용 버튼과 화면의 비교값이 동일한 계산결과를 사용하도록 통합
