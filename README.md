# 전기차 요금설계 및 매출영향 분석 시뮬레이터(PRAS-EV)

## 영문명

Pricing and Revenue Analysis Simulator - EV Charging

## 웹사이트

https://kiraoov-blip.github.io/pras-ev/

## 1. 목적

2025년 제주 전기차 완속·급속 충전 사용량을 2026년 전기자동차 충전전력요금에 적용하여, 시간대 지정 할인요금 도입 시 전력량요금 매출과 2025년 제주 SMP 기준 구입비 영향을 함께 검토하는 정적 웹 시뮬레이터입니다.

## 2. 현재 반영 기준

- 분석대상: 2025년 제주 전기차 완속 50kW 미만, 급속 50kW 이상 시간대별 사용량
- 산정범위: 기본요금 제외, 전력량요금만 산정
- 시간정의: H01 = 00:00~01:00, H24 = 23:00~24:00
- 단위: kWh
- 신규 기본 할인시간: 10:00~16:00
- 기준요금: 2026년 전기자동차 충전전력요금
- 2025년 1월 27일: 평일로 보정
- 기존 봄·가을철 주말 11:00~14:00 전력량요금 50% 할인: 체크박스로 반영 여부 선택
- 기존 주말할인과 신규 할인 중복: 체크박스로 중복 허용 여부 선택
- SMP 기반 구입비: 2025년 제주 시간대별 SMP(원/kWh) × 시간대별 충전사용량(kWh)
- SMP 영향 가정: 부하이전에 따른 SMP 자체의 변화는 없으며 실제 2025년 시간대별 SMP를 기준안과 신규요금안에 동일 적용

## 3. 주요 기능

1. 현행 매출과 신규요금 적용 후 매출 즉시 비교
2. 완속·급속별 현행 요금유형 선택
3. 신규 할인시간, 할인율, 고정단가, 비할인시간 단가조정률 변경
4. 요금제 참여율 조정
5. 완속·급속별 부하이전율 조정
6. 중간부하·최대부하 등 이전 원천 시간대 선택
7. 매출중립을 위한 할인시간 고정단가 자동 계산 및 적용
8. 0.1원/kWh 단가 조정에 따른 매출 영향 즉시 확인
9. 매출중립을 위한 비할인시간 매출중립 근사 조정률 자동 계산 및 적용
10. 24시간 평균 충전부하 및 월별 매출 차트 제공
11. 매출변동 요인분해 및 시간대별 결과 CSV 다운로드
12. 기준안과 신규요금의 SMP 기반 구입비 및 증감 비교

## 3-1. 매출중립 기능의 해석

- `매출중립 근사 조정률 적용`: 정확한 비할인시간 조정률을 계산한 뒤 가장 가까운 0.1%p 값을 적용합니다. 따라서 소액의 잔여 매출차이가 발생할 수 있습니다.
- `매출중립 할인시간 단가`: 이론상 매출증감이 0원이 되는 할인시간 고정단가를 계산하고, 입력에는 가장 가까운 0.1원/kWh 값을 적용합니다.
- `매출중립 근사단가 적용`: 정확값에 가장 가까운 0.1원/kWh 단가를 적용하며 소액의 잔여 매출증감이 발생할 수 있습니다.

## 5. GitHub Pages 배포 절차

### 1단계: 저장소 생성

GitHub에서 신규 저장소를 생성합니다.

예시 저장소명:

```text
pras-ev
```

Public 저장소로 만들면 GitHub Pages 설정이 가장 단순합니다.

### 2단계: 파일 업로드

이 폴더 안의 파일과 `data` 폴더를 저장소 최상위 경로에 그대로 업로드합니다.

GitHub 웹 화면 기준:

1. `Add file` 클릭
2. `Upload files` 선택
3. `index.html`, `styles.css`, `app.js`, `README.md`, `data` 폴더 업로드
4. Commit message 입력
5. `Commit changes` 클릭

### 3단계: GitHub Pages 활성화

저장소에서 다음 경로로 이동합니다.

```text
Settings → Pages → Build and deployment
```

아래와 같이 설정합니다.

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

저장 후 1~3분 뒤 접속주소가 표시됩니다.

### 4단계: 초기 검증

웹페이지가 열리면 다음을 확인합니다.

- 상단 제목이 정상 표시되는지
- 기본 할인시간이 10:00~16:00으로 설정되어 있는지
- 핵심 결과 카드와 매출중립 할인시간 단가 분석 카드가 표시되는지
- 24시간 평균 충전부하 차트가 표시되는지
- 할인율, 참여율, 이전율 변경 시 결과가 즉시 바뀌는지

### 5단계: 데이터 교체 방식

향후 사용량 데이터를 업데이트할 경우 `data/ev_usage_2025.js`와 `data/ev_usage_2025.json`을 교체합니다. SMP 기준연도를 변경하려면 `data/smp_jeju_2025.js`와 `data/smp_jeju_2025.json`도 해당 연도 데이터로 교체해야 합니다.

브라우저는 `ev_usage_2025.js`를 우선 사용하므로, 데이터 업데이트 시 JS 파일의 형태는 다음 구조를 유지해야 합니다.

```javascript
window.EV_USAGE_DATA = { ... };
```

## 6. 단계별 고도화 계획

### MVP 1단계: 현재 버전

- 제주 전체 완속·급속 집계 사용량 기반 매출 영향 산정
- 전력량요금만 분석
- 할인시간, 할인율, 고정단가, 참여율, 부하이전율 사용자 조정
- 매출중립 할인시간 단가와 0.1원/kWh 민감도 제시
- GitHub Pages 배포

### 2단계: 요금유형 구성비 반영

현재는 완속·급속별로 하나의 요금유형을 선택하는 구조입니다. 실제 매출과 맞추려면 완속·급속별로 다음 구성비를 추가하는 것이 좋습니다.

- 자가소비용 저압·고압 비중
- 충전서비스 제공사업자용 저압·고압 비중
- 선택Ⅰ~Ⅳ 비중

### 3단계: 고객군별 분석

고객 또는 충전사업자 단위 자료가 있으면 다음 기능을 추가할 수 있습니다.

- 고객군별 참여율
- 고객군별 부하이전율
- 고객군별 매출 증가·감소 분포
- 완속·급속 외 충전소 유형별 분석

### 4단계: 기본요금 및 계약전력 반영

계약전력 또는 충전소별 최대수요전력 자료가 확보되면 기본요금을 포함할 수 있습니다.

- 현행 기본요금 매출
- 할인시간 집중에 따른 계약전력 증가 가능성
- 기본요금 포함 총매출 영향

### 5단계: 배전망 영향 검토

지역·충전소·변압기 단위 사용량이 확보되면 요금제 도입에 따른 부하집중 리스크를 분석할 수 있습니다.

- 할인시간대 신규 피크 발생 여부
- 특정 지역 충전부하 집중도
- 변압기·피더 단위 수용여력 영향

## v2.9 변경사항

- 사용자 제공 `smpJeju_2025.xlsx`의 2025년 제주 일자별·시간대별 SMP 8,760개 값을 시뮬레이터 데이터로 추가했습니다.
- 상단 3×3 핵심 결과의 `연중 최대 시간사용량 변화` 다음에 별도 `SMP 기반 구입비 영향` 영역을 추가했습니다.
- `기준안 SMP 기반 구입비 = Σ(기준 시간대별 사용량 × 해당 시간대 제주 SMP)`로 계산합니다.
- `신규요금 SMP 기반 구입비 = Σ(부하이전 후 시간대별 사용량 × 동일 시간대 제주 SMP)`로 계산합니다.
- `SMP 기반 구입비 영향 = 신규요금 구입비 - 기준안 구입비`로 표시하며, 음수는 구입비 절감, 양수는 구입비 증가를 의미합니다.
- 부하이전에 따른 SMP 자체의 변화는 없다고 가정합니다.
- 기본 설정(참여율 80%, 완속 이전율 50%, 급속 이전율 30%, 10~16시 할인시간, 경·중간·최대부하 모두 이전 원천)에서는 기준안 약 89.3억 원, 신규요금 약 90.0억 원, 구입비 영향 약 +0.7억 원으로 계산됩니다.
